# Server4Agent Skills

Agent Skills for [Server4Agent](https://www.server4agent.com): hosted servers, projects and live URLs for AI agents.

## Install

```
smithery skill add server4agent/server4agent
npx skills add Server4Agent/server4agent-skills
```

MCP server: `https://mcp.server4agent.com` (OAuth, or an `X-API-Key` header).
